MKV Muxer 2.0
==============

Пакетное добавление аудиодорожек в MKV-файлы.

Системные требования
--------------------
Windows 10/11, 64-бит.
MKVToolNix устанавливать НЕ нужно: mkvmerge v103.0 уже встроен в программу.

Как пользоваться
----------------
1. Запустите MKV_Muxer.exe.
2. Поле mkvmerge заполняется автоматически (встроенная копия во временной папке).
   Менять этот путь не нужно.
3. Укажите папку с видеофайлами .mkv.
4. Укажите папку с аудиофайлами (.mka, .ac3, .aac, .flac, .dts, .mp3, .eac3, .m4a, .wav).
   Программа не просматривает подпапки: выбирайте папку, где лежат файлы
   непосредственно, например "RUS Sound [StudioBand]".
5. Укажите папку сохранения либо оставьте её пустой.
6. Нажмите "Запустить".

Режимы сохранения
-----------------
- Папка сохранения указана  -> готовые файлы пишутся туда под теми же именами.
- Папка пуста + галочка _new -> рядом с оригиналом создаётся файл с суффиксом _new.
- Папка пуста без галочки    -> оригинал заменяется (программа попросит подтверждение).

Серия определяется по имени файла: S01E05, E05, Ep05, Episode 5, а также
по числу, отделённому пробелом, точкой, дефисом или подчёркиванием.

Что внутри
----------
- MKV_Muxer.exe — программа. В portable-архиве это один файл; в установленной
  версии рядом находится служебная папка _internal (её нельзя удалять).
- mkv_muxer.py  — исходный код (GPL-2.0-or-later).
- LICENSES\     — тексты лицензий, включая GPL-2.0 и лицензии MKVToolNix.
- SHA256SUMS.txt — контрольные суммы файлов (в portable-архиве).

Проверка целостности
--------------------
Сверьте SHA256 файла с указанным в SHA256SUMS.txt:
  certutil -hashfile MKV_Muxer.exe SHA256

Антивирус и SmartScreen
-----------------------
Программа не подписана. Windows SmartScreen может показать предупреждение
"Неизвестный издатель" — это нормально для неподписанных сборок.
Если антивирус жалуется на EXE, добавьте файл в исключения.
Ложные срабатывания на PyInstaller-сборки — известная проблема.
